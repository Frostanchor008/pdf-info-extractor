# 项目说明

## 项目名称

PDF 信息批量提取与 Excel 导出工具

## 项目简介

本项目是一个面向办公自动化接单场景的 Python 小工具。用户可以上传或批量读取 PDF 文件，系统自动提取常见字段，并导出为 Excel 或 CSV。

它适合作为新手接单作品集项目，也适合给客户演示“PDF 转 Excel 自动化整理”的基础能力。

## 目标用户

- 行政、财务、人事、教务等需要整理 PDF 表格信息的人员
- 有批量 PDF 资料需要录入 Excel 的小微企业
- 需要快速验证自动化方案的客户

## 当前功能

- 批量读取 PDF
- 自动提取文本
- 提取编号、日期、客户、金额、税号、电话、邮箱
- 表格预览
- CSV 导出
- Excel 导出
- 命令行和 Streamlit 网页两种使用方式

## 技术栈

- Python
- Streamlit
- pandas
- pdfplumber
- pypdf
- openpyxl

## 项目边界

当前版本不做 OCR，不接入 AI API，不处理登录系统，不做爬虫，不绕过验证码。它只处理用户本地提供的 PDF 文件。

如果客户的 PDF 是扫描件或图片型 PDF，需要另行评估 OCR 升级版。
