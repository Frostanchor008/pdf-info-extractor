# 需求确认清单

接单前建议逐项确认，避免返工。

## 文件情况

- PDF 数量：
- 每份 PDF 页数：
- PDF 是否可以复制文字：
- 是否有扫描件或图片型 PDF：
- 是否有多个模板：
- 是否能提供 3-5 份样本：

## 字段需求

- 需要提取的字段：
- 字段名称是否固定：
- 是否需要保留原文件名：
- 是否需要保留页数：
- 是否需要保留提取失败原因：
- 是否需要文本预览：

## 导出需求

- 导出格式：Excel / CSV
- 是否需要固定列顺序：
- 是否需要固定 Excel 模板：
- 是否需要合并到一个文件：
- 是否需要按客户、日期或类型分类：

## 使用方式

- 命令行批处理：
- Streamlit 网页界面：
- 是否需要打包 exe：
- 是否需要远程部署：

## 验收标准

- 样本 PDF 提取准确率：
- 允许的人工校对范围：
- 交付文件清单：
- 交付时间：
- 后续修改次数：

## 合规确认

- 文件由客户主动提供：
- 不涉及平台登录：
- 不绕过验证码：
- 不自动投标：
- 不自动私信：
- 不违反平台规则：
