# 接单报价模板

## 报价前需要确认

- PDF 是否可以复制文字
- 是否为扫描件或图片型 PDF
- 大约有多少份 PDF
- 每份 PDF 平均多少页
- 需要提取哪些字段
- 字段名称是否固定
- 是否需要固定 Excel 模板
- 是否需要本地网页界面
- 是否需要打包成 exe
- 是否涉及敏感数据

## 基础版报价

适用情况：

- 电子 PDF
- 字段固定
- 字段数量不超过 8 个
- 不需要 OCR
- 不需要复杂模板

参考报价：300-500 元

交付周期：1-2 天

## 定制版报价

适用情况：

- 字段数量较多
- 多种 PDF 模板
- 需要适配客户样本
- 需要优化导出 Excel 样式

参考报价：500-1000 元

交付周期：2-5 天

## OCR 升级版报价

适用情况：

- 扫描件 PDF
- 图片型 PDF
- 需要识别图片中的文字

参考报价：800 元起

交付周期：视样本质量评估

## 可发送给客户的报价话术

您好，我看了您的需求。如果 PDF 是可以复制文字的电子版，并且字段格式比较固定，我可以做一个本地运行的小工具，批量提取字段并导出 Excel。

基础版报价为 300-500 元，具体价格取决于字段数量和样本复杂度。建议您先发 3-5 份样本 PDF，我确认可提取效果后再给最终报价和交付时间。

如果是扫描件或图片型 PDF，需要做 OCR 识别，费用会高一些，需要单独评估。
