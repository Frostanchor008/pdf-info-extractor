# 客户演示话术

## 开场介绍

您好，这是一个本地运行的 PDF 信息提取工具，适合把格式固定的 PDF 批量整理成 Excel。比如发票、订单、合同回执、报名表、对账单等。

## 演示步骤

1. 我先打开本地网页工具。
2. 上传几份样本 PDF。
3. 工具会自动识别编号、日期、客户、金额、电话、邮箱等字段。
4. 识别结果会显示在页面表格中。
5. 确认无误后，可以一键下载 CSV 或 Excel。

## 需求确认话术

为了保证提取准确率，我需要先看 3-5 份样本 PDF，确认这些 PDF 是否有文本层，以及字段名称是否固定。

如果样本格式统一，通常可以做基础版。如果是扫描件图片，则需要 OCR 升级版。

## 交付说明

基础版可以交付：

- 可运行的 Python 项目
- 本地网页操作界面
- Excel / CSV 导出功能
- 简单使用说明

如果您希望给同事直接使用，也可以后续增加打包成 exe、固定导出模板、字段配置表等功能。

## 风险提示

当前基础版适合电子 PDF。如果 PDF 是图片扫描件，文本无法直接复制，需要 OCR 识别，开发成本和准确率评估会不同。
